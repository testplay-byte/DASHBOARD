# Screenshots

Per-round screenshot zips for ACUTE-CODE. Each round's verification capture
is published here by `scripts/dashboard/publish-screenshots.mjs` in the
private ACUTE-CODE repo (Workstream K, Round 28 master plan).

This directory is NOT part of the dashboard build (`build.mjs`); the zips
are served as raw static files by GitHub Pages alongside `index.html`.

## Index

See `index.json` for the machine-readable list. Each entry:
`{ round, date, zip, size_bytes, screenshots }`.
